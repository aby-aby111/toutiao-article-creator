# 今日头条文章规范参考

## 一、标题规范

今日头条标题是决定点击率的核心要素，需严格遵守以下规则：

### 标题公式（按效果优先级排列）
1. **数字冲击型**：`{数字}+{核心事实}+{悬念}` 例："3个信号暗示房价即将触底，第2个很多人没想到"
2. **对比冲突型**：`{A} vs {B}+{反转/反差}` 例："同样年薪30万，体制内和互联网大厂的差距究竟有多大？"
3. **疑问/悬念型**：`{为什么/如何/是否}+{热点事件}+{未解之谜}` 例："为什么日本核污水排海后，最先反对的竟是渔民自己？"
4. **情绪共鸣型**：`{情感词}+{群体}+{痛點}` 例："月薪5000的年轻人们，正在被这3座大山压垮"

### 标题硬性要求
- 字数：**20-30字**，超出即不合格，一个字都不能多
- 必须包含核心关键词（与热点事件密切相关的词）
- 避免标题党：不能夸大事实、不能误导、不能与正文不符
- 适当使用标点：引号、问号、感叹号（但不超过1个感叹号）
- 禁止使用「震惊」「出大事了」「紧急通知」等低质诱导词
- **自检**：写出后将标题逐字编号计数，确认在20-30字之间

## 二、文章结构规范

### 总体结构
```
┌─ 主标题（一个，不设副标题）
├─ 导语段（80-120字，概述核心事件+制造悬念）
├─ 正文段落（3-6段，每段80-150字）
│   ├─ 段落1：事件背景/最新进展
│   ├─ 段落2：核心争议/关键细节
│   ├─ 段落3：多方观点/深度分析
│   ├─ 段落4：影响与后果
│   └─ 段落5：未来展望/相关延伸
├─ 配图说明（每段之间插入1张配图）
└─ 结尾段（引发讨论/引导互动）
```

### 段落规范
- 每段不超过 **2行**（手机屏幕计，约75字以内）
- 核心短句可 **独占一段**，制造视觉节奏感
- 段间空一行，保持阅读呼吸感
- 首句必须有力，能用一句话概括该段核心
- **关键数据、时间、船名、引语加粗**，制造视觉锚点
- 避免大段文字堆砌，多分段
- 善用 **"引号"** 作为段落起手式，增强口语感

### 语言风格
- **口语化但不失专业性**：用"你知道吗""很多人不知道的是"等口吻，但不丢失事实依据
- **数据说话**：每个观点必须有数据支撑或权威来源
- **短句为主**：平均句长不超过25字
- **避免生僻词**：用"买不起房"代替"购房困难"等书面表达
- **适当使用设问**：自问自答增加互动感

## 三、配图规范

### 配图数量
- 文章500-800字：**4-5张配图**
- 文章800-1500字：**5-7张配图**
- 避免连续无图文段超过 **2段**（约150字）

### 配图类型
1. **新闻现场图**：事件发生地的真实照片风格（AI生成时写实风格）
2. **数据可视化图**：关键数据的图表/信息图呈现
3. **人物/表情图**：关键人物或能表达情绪的图片
4. **场景氛围图**：能烘托主题氛围的场景图
5. **对比/分析图**：用于展示对比或分析的示意图

### 配图位置规则
- 第一张图：导语段 **正下方**（吸引继续阅读）
- 中间图：**每1-2段之间**均匀分布，保持阅读节奏
- 最后一张图：**结尾互动段紧挨着上方**（提升分享欲）
- 图与图之间至少间隔1段文字

## 四、内容基本要求

### 信息核实
- 所有事实数据必须有来源（标注来源）
- 多方观点要平衡呈现，不偏颇
- 涉及争议话题要注明「截至发稿前」等时间定语

### 错别字与格式
- 零错别字
- 中英文标点混用需统一（优先使用中文标点）
- 数字使用阿拉伯数字
- 专有名词要保持一致性

## 五、互动引导规范

### 结尾要求
- 必须设置互动问题（如：「对此你怎么看？欢迎在评论区讨论」）
- 可以设置投票式引导（如：「支持的点个赞，反对的说说理由」）
- 可以设置下期预告（如：「关注我，下期带你深扒XX内幕」）

### 禁止行为
- 不设"转发到家族群"等诱导分享
- 不设"不转不是中国人"等情感绑架
- 不过度使用"你中招了吗""说的就是你"等PUA式标题
