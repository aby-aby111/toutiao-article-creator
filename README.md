# 今日头条文章创作者 (Toutiao Article Creator)

基于社会实时热点，创作符合今日头条平台规范的爆款文章，并生成 AI 配图提示词，明确标注每张图片的放置位置。

---

## 功能特性

- **实时热点追踪**：自动搜索微博、百度、微信等多平台热搜，发现当下最热话题
- **智能选材**：根据热度数值和新闻价值自动筛选最适合创作的热点
- **爆款标题生成**：遵循 20-30 字规范，采用数字冲击、对比冲突、悬念疑问等公式
- **手机端排版优化**：段落极短化、数据加粗、视觉分隔符，适配移动阅读习惯
- **AI 配图生成**：为文章生成多张配图提示词，覆盖新闻纪实、信息图表、情感特写等多种风格
- **互动引导**：结尾设反问句引导评论，提升互动率
- **双模式运行**：支持人机交互和完全自动化的定时任务两种模式

## 工作模式

### 交互模式

适合用户在线、需要参与选择的场景。

**第0步：热点发现（可选）**

用户说"有什么热点"时，搜索多平台热搜，整理为分类列表供选择。

**第1步：接收热点主题**

搜索该事件的详细信息：最新进展、关键数据、多方观点、网友评论。

**第2步：搜索补充素材**

自动搜索 `{热点关键词} 最新进展`、`{热点关键词} 数据`、`{热点关键词} 官方回应`。

**第3步：拟定标题**

拟定 3 个备选标题（20-30 字），由用户选择。自检清单：
- [ ] 字数是否在 20-30 字之间？
- [ ] 是否包含核心事件关键词？
- [ ] 是否有"第1眼吸引力"？
- [ ] 是否避免了「震惊」「紧急通知」等标题党词？

**第4步：撰写正文**

按"手机排版铁律"撰写完整文章。

**第5步：生成配图提示词**

使用英文，包含场景、主体、风格、构图、画质参数。

**第6步：输出文章**

按标准格式输出完整文章。

---

### 自动化模式（无交互场景）

适合 Cron 定时任务、机器人推送等环境。检测到 `automation_trigger` 标识时自动进入。

**核心原则：** 无等待、自主决策、一次完成、质量优先。

**自动化流程：**
| 步骤 | 操作 |
|------|------|
| A1 | 搜索多平台热点，按热度判定筛选（>50万或重大新闻） |
| A2 | 搜索补充素材：最新进展、数据、官方回应 |
| A3 | 拟定3个标题，AI 自行选择最佳，执行字数自检 |
| A4 | 撰写正文+配图，遵循"手机排版铁律" |
| A5 | 直接交付完整文章，不做二次确认 |

## 标题规范

### 标题公式

| 类型 | 格式 | 示例 |
|------|------|------|
| 数字冲击型 | `{数字}+{核心事实}+{悬念}` | "3个信号暗示房价即将触底，第2个很多人没想到" |
| 对比冲突型 | `{A} vs {B}+{反转/反差}` | "同样年薪30万，体制内和大厂的差距有多大？" |
| 疑问/悬念型 | `{为什么}+{事件}+{未解之谜}` | "为什么核污水排海后，最先反对的竟是渔民自己？" |
| 情绪共鸣型 | `{情感词}+{群体}+{痛點}` | "月薪5000的年轻人，正在被这3座大山压垮" |

### 硬性要求

- 字数：**20-30 字**，超出即重写
- 包含核心事件关键词
- 感叹号不超过 1 个
- **禁止**："震惊""出大事了""紧急通知"等词

---

## 手机排版铁律

### 1. 段落极短化
每段不超过 **2 行**（约 75 字），核心句可独占一段。

### 2. 关键数据加粗
数据、时间、专有名词、关键引语用 `**加粗**` 制造视觉锚点。

### 3. 视觉分隔符
段落之间必须空行，可用 **"引号"** 作为段落起手式。

### 4. 配图加密分布
- 500-1000 字 → 4-5 张图
- 1000 字以上 → 5-7 张图
- 位置：导语段下方 → 每1-2段间 → 结尾段上方

### 5. 有力结尾
用 `【】` 标注互动段，反问句收尾。

## 配图规范

### 文章类型与配图策略

| 类型 | 第1张 | 第2张 | 第3张 | 第4张 |
|------|-------|-------|-------|-------|
| 社会热点 | 事件现场（新闻纪实） | 数据图表（信息图） | 人物特写（情感） | 对比/展望（插画） |
| 科技 | 产品展示（产品摄影） | 数据趋势（信息图） | 使用场景（插画） | 行业格局（信息图） |
| 民生 | 生活场景（新闻纪实） | 数据支撑（信息图） | 情绪特写（情感） | 美好愿景（插画） |

### 提示词结构
```
[场景描述] + [主体细节] + [风格/氛围] + [构图/视角] + [技术参数]
```

### 位置标注格式
```
[图片位置: 导语段之后]
[配图提示词: Photojournalism style, ... , 4K, high detail]
```
